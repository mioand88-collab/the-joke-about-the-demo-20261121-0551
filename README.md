A one-line joke about working beside an AI coding agent, written for a live demo that goes wrong in exactly the way only an agent could manage: the agent fixes the bug in ten seconds flat, then, with total confidence, turns its helpfulness on the demo itself. Run it with Node 22: `node main.ts` (or set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written).
